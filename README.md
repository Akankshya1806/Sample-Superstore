This project analyzes the Sample Superstore dataset to understand sales performance, profitability, customer behavior, and product trends.

The goal of this project is to transform raw sales data into meaningful business insights using data cleaning, analysis, visualization, and interactive dashboards.

🎯 Objectives
- Analyze overall sales and profit performance
- Identify the most profitable and least profitable products
- Understand sales performance across different regions and states
- Analyze customer segments and shipping modes
- Identify trends in sales and profit over time
- Find products and categories that contribute significantly to revenue
- Build an interactive dashboard for business decision-making

🗂️ Dataset: The project uses the Sample Superstore dataset, which contains information about: Orders, Customers, Products, Categories and sub-categories, Sales, Profit, Discounts, Quantity, Shipping, Regions and states, Order and shipping dates

🛠️ Tools & Technologies
Excel / CSV – Source data
GitHub – Project documentation and version control

📊 Key KPIs
The dashboard focuses on important business metrics such as:
- Total Sales
- Total Profit
- Total Orders
- Total Quantity Sold
- Average Order Value

📈 Dashboard
The dashboard provides an interactive view of:
- Sales Analysis
- Sales by year and month
- Sales by category and sub-category
- Sales by region and state
- Profit Analysis
- Profit by category
- Profit by sub-category
- Most and least profitable products

💡 Key Insights
Some of the business questions explored in this project include:

Which category generates the highest sales?
Which category and sub-category generates the highest profit?
Which states are the most profitable?
Which products generate losses?
How do discounts affect profitability?
Which customer segment contributes the most revenue?
Which region performs best in terms of sales and profit?
How have sales and profit changed over time?
